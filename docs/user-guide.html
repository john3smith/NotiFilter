01

어떤 일을 하나요?

문구 규칙

대상 앱과 포함 문구를 정하고 규칙별 스위치로 관리합니다. 규칙 카드를 터치하면 기존 조건을 수정하고 저장할 수 있으며, 순서와 활성 상태를 유지합니다.

앱 선택

아이콘과 앱 이름·패키지 검색을 통해 대상을 찾습니다. 추가 팝업은 중복으로 열리지 않습니다.

기존 알림 검사

새 규칙 저장, 활성 규칙 수정 저장, 규칙 재활성화, 전체 일시정지 해제 때 현재 떠 있는 알림도 검사합니다.

삭제 이력

삭제 확인 시각·제목·본문·앱과 아이콘을 최신순 최대 1,000개 저장합니다.

02

처음 사용하기

  1. APK를 설치하고 알림 접근 설정 열기에서 NotiFilter 권한을 직접 허용합니다.
  2. 규칙 추가를 누르고 아이콘·검색으로 앱을 고르거나 모든 앱을 선택합니다.
  3. 차단할 포함 문구를 입력하고 저장합니다. 너무 짧고 흔한 문구는 정상 알림까지 지울 수 있습니다.
  4. 전체 필터와 규칙 스위치 상태를 확인합니다.
  5. 삭제한 알림 이력을 열고 새로고침하여 실제 삭제 확인 내역을 봅니다.
03

자주 쓰는 기능

토글
켜는 순간에는 기존 알림도 검사합니다. 끄는 순간에는 삭제하지 않습니다. 전체 일시정지 중이거나 권한이 없으면 작동하지 않습니다.
팝업
추가 버튼을 여러 번 눌러도 하나만 열립니다. 취소 또는 Android 뒤로가기로 닫을 수 있습니다.
이력
OS가 리스너에 의한 삭제를 확인한 항목만 기록합니다. 사용자 수동 삭제·실패한 제거 요청은 이력에 넣지 않습니다.
04

문제가 생겼을 때

규칙이 작동하지 않습니다
알림 접근, 전체 일시정지, 해당 규칙의 스위치와 실제 문구를 확인하세요.
알림이 잠깐 보입니다
게시 후 제거하는 방식의 한계입니다. 원래 앱에서 해당 알림 종류를 끄는 방법도 검토하세요.
이력이 비어 있습니다
권한과 새로고침을 확인하세요. OS의 삭제 확인이 없으면 성공으로 기록하지 않습니다.
05

데이터와 보안

  • 규칙·이력은 기기 내부에만 저장하며 인터넷 권한이 없습니다.
  • 이력에 개인정보가 포함될 수 있습니다. 클라우드 백업·기기 전송에서는 제외하며, 이력 기능 도입 이전 삭제 내역은 복구하지 못합니다.
06

알아두실 제한사항

  • 알림 게시 후 제거하므로 잠깐 화면 표시나 소리가 발생할 수 있습니다.
  • 일부 시스템·지속 알림은 제거할 수 없습니다. 리스너 연결 중단 직전의 확인은 이력에서 누락될 수 있습니다.
  • 앱 시작·리스너 재연결만으로 기존 알림을 지우지는 않습니다. 지운 알림을 이력에서 원래 알림으로 복원하는 기능은 아닙니다.
